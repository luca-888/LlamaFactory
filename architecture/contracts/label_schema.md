# Label Schema - Scene Understanding

## 1. 行为标签（闭集）
允许集合：
- `合规驾驶`
- `高风险驾驶`
- `特殊驾驶`
- `不合理驾驶`
- `违规驾驶`

风险优先级（用于多标签收敛主标签）：
- `违规驾驶 > 高风险驾驶 > 不合理驾驶 > 特殊驾驶 > 合规驾驶`

兼容映射：
- `危险驾驶 -> 高风险驾驶`
- `不当驾驶 -> 不合理驾驶`

## 2. 静态字段映射（规范化）
- 天气：`雷雨 -> 雨天`，`霾_雾霾 -> 雾天`
- 光照：`强光 -> 逆光`
- 特殊障碍物：`事故车辆 -> 其他路面异物`，`三角警示牌 -> 其他路面异物`
- 道路区域：`内部道路 -> 城区干道`

## 3. 动态标签映射（规范化）
- `自车换道_导航换道 -> 自车换道`
- `自车换道_效率换道 -> 自车换道`
- `掉头(uturn） -> 掉头(uturn)`

## 4. 管理规则
- 本文件是标签与映射唯一可信来源（SSOT）。
- 新增标签必须同步更新：
  - `DATA_STATE.md`（数据事实）
  - `architecture/contracts/metric_spec.md`（评估口径）
