# Task Spec - Scene Understanding

## 1. 任务定义
- 任务名：`scene_understanding_v1`
- 范围：仅 VLM 场景理解，不包含 RL、Agent、工具调用。
- 输入：`<video>` + 结构化先验（静态环境字段 + 动态事件区间）。
- 输出：严格 JSON，包含 `动态标签`、`静态标签`、`行为标签` 三个顶级 key。

## 2. 输入模态与约束
- 视频：`/f900/APS/tag_system/{session_id}.mp4`
- 视频时间基准：4fps，15s。
- 动态事件标注基准：原始 frame 范围 `[0,600]`。
- 结构化先验字段：天气、光照、道路区域、道路类型、特殊静态要素、特殊障碍物、动态事件。

## 3. 输出契约（高层）
- `动态标签`：列表，元素含 `标签` 与 `时间范围`（秒）。
- `静态标签`：对象，固定 6 个字段。
- `行为标签`：列表，当前阶段按单主标签使用（长度建议为 1）。

## 4. 非目标
- 不生成解释文本。
- 不做链式思考输出。
- 不做多任务混训调度。

## 5. 版本
- `v1`（2026-02-13）：三类标签联合输出契约。
